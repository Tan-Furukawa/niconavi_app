# NicoNavi v0.3.0-beta
[![DOI](https://zenodo.org/badge/1111962451.svg)](https://doi.org/10.5281/zenodo.17861277)

see https://tan-furukawa.github.io/niconavi/

## Running from source

```bash
python niconavi.py
```

NicoNavi opens in its own desktop window. To run the optional browser version,
use `python niconavi.py --web`.

## Packaging

PyInstaller-free packaging scripts are available for a Windows x64 installer
and an Ubuntu/Linux x86_64 AppImage. See [packaging/README.md](packaging/README.md).
